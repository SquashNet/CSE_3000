# Security Statement

## Intended users

This repo holds my work for CSE 3000. It is a fork of the course repo, batmandoescalc/code_3000. The intended users are me and the course staff who grade my work.

## Risk

The risk is low.

- The repo is public, so anyone can see it.
- There are no passwords, API keys, or tokens in the repo.
- The data files are the same as the ones in the public course repo. Someone who takes them gets nothing new.
- The main risk is that another student could copy my homework answers.

## Steps taken

- The .gitignore file keeps my local Python environment (3000-env) and .DS_Store files out of the repo.
- I have not set up code owners or branch rules. I do not think they are needed, because the repo has no secrets and its data is already public.
